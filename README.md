# Student Attendance Tracker

## Introduction
Student Attendance Tracker is a Python-based attendance management system.
It helps to record student attendance, calculate attendance percentage,
identify defaulters, and generate attendance reports.

## Objectives
- Add and manage student details
- Mark daily attendance
- Store attendance records
- Calculate attendance percentage
- Identify students with attendance below 75%
- Generate attendance reports

## Technologies Used
- Python
- CSV File Handling
- Git
- GitHub

## Features
- Add Student
- View Students
- Mark Attendance
- Attendance Percentage
- Defaulter Detection
- Attendance Report
- Basic Input Validation

## How It Works
1. Add student name and roll number.
2. Mark attendance as Present (P) or Absent (A).
3. Attendance is stored with the date.
4. The system calculates attendance percentage.
5. Students below 75% attendance are identified as defaulters.
6. An attendance report is generated.

## Attendance Formula

Attendance Percentage = (Present Days / Total Attendance Days) × 100
